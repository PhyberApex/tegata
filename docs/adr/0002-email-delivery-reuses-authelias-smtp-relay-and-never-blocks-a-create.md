# Email Delivery reuses Authelia's SMTP relay and never blocks a create

Email Delivery needed SMTP credentials from somewhere, and a deployment that runs Authelia already has exactly one relay configured: the one Authelia's own notifier sends through. Tegata's `SMTP_*` variables are meant to point at that same host, port and credentials rather than a second mailbox — one relay to rotate instead of two, at the cost of Tegata and Authelia sharing a blast radius if that mailbox's credentials leak or get rate-limited. Nothing enforces the sharing; it is the recommended shape, and the example compose file and `.env.example` show it.

The send itself is deliberately soft, and deliberately not awaited. `InvitesService.createInvite` and `ResetTokensService.createResetToken` insert the row, fire the send without awaiting it, and return immediately — the outcome (`email_sent_at` or `email_error`) lands on the row later via a `.then()` callback. `MailService` never throws or rejects; every failure mode (unconfigured SMTP, network error, rejected recipient) is normalized into a returned `{ error }`, so the callback's own write is the only thing that still touches the database once the create has already responded. Not awaiting is what makes the "never blocks" guarantee real rather than aspirational: an awaited send couples the create's response time to an external relay's health, and a relay that's merely slow (not actively refusing) would otherwise stall the request for the full connection/greeting/socket timeout regardless of how the failure itself is handled. It also sidesteps a narrower race — an admin revoking the token while an awaited send was still in flight would hit a `getById(id)!` non-null assertion against a since-deleted row; an update against a row that no longer exists is just a silent no-op instead. This mirrors the Out-of-Band Edit precedent: the copy-link and QR paths are the fallback of record, not a secondary option, so a bounced, slow, or misconfigured mail server must never be the reason a token can't be created — or the reason creating one feels slow.
